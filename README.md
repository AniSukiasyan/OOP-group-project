# Quiz Game

## Overview
OOP Quiz Game is a Java-based quiz application developed using Object-Oriented Programming principles.  
The project includes both a GUI mode and a console mode, allowing users to answer different types of programming-related questions with varying difficulty levels.

The game supports:
- Multiple Choice Questions
- True/False Questions
- Fill in the Blank Questions
- Code Completion Questions

---

## Features

- Object-Oriented Design
- GUI and Console gameplay modes
- Difficulty levels:
    - Easy
    - Medium
    - Hard
    - Extremely Hard
- Score tracking system
- Exception handling
- Randomized quiz generation
- JavaDocs documentation

## How to Run

### Using IntelliJ IDEA
1. Open the project in IntelliJ IDEA.
2. Mark the src folder as Sources Root.
3. Run:
   text    OOPGroupWork.quizgame.QuizGame

### Using Terminal
Compile:
bash javac -d out $(find src -name "*.java")

Run:
bash java -cp out OOPGroupWork.quizgame.QuizGame
